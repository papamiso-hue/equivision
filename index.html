Core Technology

독자적인 비전 AI 원천 기술

ENGINE 01

다중 관절 비전 포즈 분석

예시장 영상에서 경주마의 두부, 경부, 전구, 후구 등 주요 골격 관절을 감지합니다. 보폭(Stride), 보행 주기(Gait Cadence), 좌우 대칭성을 프레임 단위로 수치화합니다.

ENGINE 02

시계열 생체역학 컨디션 평가

보행 리듬의 미세 변화, 걸음걸이의 탄성, 추진 각도 변화를 해당 마필의 과거 기록과 비교합니다. 당일 보행 밸런스와 평소 대비 변화량을 객관적인 컨디션 지수로 산출합니다.

ENGINE 03

경주 데이터 융합 및 오버레이

당일 컨디션 지수에 주로 상태(함수율), 부담중량, 게이트 위치, 전개 페이스 등 경주 데이터를 다차원으로 결합하여 경주 환경 정보를 함께 정리하고, 방송·대시보드용 데이터 오버레이로 시각화합니다.

Quantitative Methodology

데이터 기반 경주 분석 방법론

주관적 직관 대신 통계 모델과 검증 가능한 지표로 경주를 분석합니다.

정량적 경주 분석(Quantitative Racing Analytics)은 직관이나 단순한 인기도에만 의존하던 기존 방식에서 벗어나, 수학·통계 모델과 데이터 알고리즘(AI·빅데이터·컴퓨터 비전)으로 경주를 계량화하여 분석하는 과학적 접근 방식입니다. 같은 데이터를 넣으면 같은 결과가 나오고, 그 결과를 과거 데이터로 검증할 수 있다는 점이 핵심입니다.

1. 방법론의 핵심 개념

01 컨디션 지표 산출

과거 주행 기록, 구간 기록, 코너링 궤적, 주로 상태, 부담중량, 게이트 위치, 그리고 예시장에서 측정한 생체역학 지표(비절 각도, 보행 탄력 등)를 변수로 정량화합니다. 이를 통계·머신러닝 모델로 정리해 각 마필의 컨디션 지표와 평소 대비 변화를 산출합니다.

02 평소 대비 변화 비교

같은 말의 이전 예시장 기록과 오늘의 지표를 비교해, 걸음의 리듬·보폭·탄력이 평소보다 좋아졌는지 나빠졌는지를 수치로 보여 줍니다.

03 경주 직전 데이터 갱신

마체중 변동, 출전 취소, 주로 상태 변화 등 경주 직전에 발생하는 데이터를 반영하여 분석 결과를 최신 상태로 갱신합니다.

04 모델 검증 (Backtesting)

학습에 쓰지 않은 과거 영상·경주 데이터로 모델을 검증합니다. 분석 결과의 일관성과 안정성을 통계 지표로 검증하고, 성능이 떨어지는 조건을 찾아 모델을 개선합니다.

2. 기존 분석 방식과의 비교

구분 기존 분석 (육안 중심) 정량적 분석 (Quantitative)
판단 기준 직관, 육안 관찰, 과거 명성 정량화된 수치, 통계 모델, 알고리즘
분석 결과 육안으로 본 인상 (사람마다 다름) 측정된 컨디션 지표와 평소 대비 변화량의 정량 제시
데이터 활용 기본 전적표, 착순 위주 시계열 주행 데이터, 비전 AI 생체역학 지표, 경주 직전 데이터
재현성 분석자마다 결론이 다름 동일 입력 → 동일 결과, 분석 로직 문서화
검증 방식 사후 주관적 복기 대량 과거 데이터 기반 통계적 백테스팅

방법론 요약

"경주마의 주행 데이터와 예시장 생체역학 지표, 경주 직전 데이터를 종합해 각 마필의 컨디션을 수치로 표현하고, 그 일관성을 통계적으로 검증하는 체계적인 데이터 분석 기법입니다."
