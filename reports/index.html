안 열릴 때
  1. 입금이 확인되기 전에는 「입금 확인 중」이라고 나옵니다. 확인은 운영자가 직접 하므로 시간이 걸릴 수 있습니다. 확인되면 같은 방법으로 다시 들어오시면 열립니다.
  2. 휴대폰 번호는 신청 때 쓰신 번호, 주문번호는 신청이 끝났을 때 화면에 나온 EV로 시작하는 글자입니다. 5번 틀리면 15분 동안 막히니 천천히 확인해 주세요.
  3. 이용 기간이 끝났거나 환불하셨다면 볼 수 없습니다.
  4. 주문번호를 잊으셨다면 equivisionai@gmail.com 로 신청하신 이름과 휴대폰 번호 뒤 4자리를 알려 주세요.

새 리포트가 올라오면 이 화면이 저절로 바뀝니다.

📱 바탕화면에 아이콘 만들기

한 번만 해 두면, 다음부터는 바탕화면의 "오늘 리포트" 아이콘만 누르면 됩니다.

아이폰이시면 이렇게 하세요.

  1. 사파리(Safari)로 이 화면을 엽니다. (다른 앱에서는 안 됩니다)
  2. 화면 아래쪽 가운데 공유 버튼(네모 위에 화살표 ⬆)을 누릅니다.
  3. 목록을 밀어 올려 "홈 화면에 추가"를 누릅니다.
  4. 오른쪽 위 "추가"를 누르면 끝입니다.

갤럭시(안드로이드)이시면 이렇게 하세요.

  1. 크롬(Chrome)으로 이 화면을 엽니다.
  2. 오른쪽 위 점 3개(⋮)를 누릅니다.
  3. "홈 화면에 추가" 또는 "앱 설치"를 누릅니다.
  4. 한 번 더 "추가"(또는 "설치")를 누르면 끝입니다.

만든 뒤에는 바탕화면에 파란 EV 글자 아이콘이 생깁니다.
